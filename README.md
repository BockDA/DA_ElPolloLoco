# 🐔 Pepe vs. Crazy Chickens – Jump & Run Game

An object-oriented **Jump-and-Run game** built with **JavaScript**, **HTML**, and **CSS**.  
Help **Pepe** save the city from a horde of crazy chickens in this fun, side-scrolling action game!

## 🎮 Game Description

A simple but entertaining platformer game:

- Play as **Pepe**, the hero of the city
- Jump, run, and fight your way through levels
- Defeat **crazy chickens** and other enemies
- Built using **object-oriented programming (OOP)** for better structure and scalability

## 🚀 Features

- ✅ 2D side-scrolling movement
- ✅ Character animations and basic physics
- ✅ Enemies with simple AI behavior
- ✅ Collision detection
- ✅ Win/Lose conditions
- ✅ Modular code using **JavaScript OOP**
- ✅ Fully responsive for desktop play

## 🛠️ Technologies Used

- **JavaScript (ES6+)** – Game logic, OOP structure, animations
- **HTML5** – Game canvas and structure
- **CSS3** – Styling and layout
